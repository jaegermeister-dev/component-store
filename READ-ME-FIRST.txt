Development components - Windows 7 driver setup

The setup wizard is used with the original publisher drivers prepared by NoMoreBCA.
It automatically installs applicable components, preserves normal UAC and driver
signature enforcement, and presents normal restart choices when necessary.
After a required restart, setup reopens once at sign-in and requests normal UAC.
Click Install to continue. If it does not reopen, run the same setup EXE again.
Results and rollback records are retained in ProgramData, in the session shown by setup.
This archive contains our installer and a download recipe, not vendor driver binaries.
MacBookPro11,5 and experimental 11,4 only; 11,4 receives no AMD packages.
Fresh hardware acceptance is still required. Fn/backlight, dock Ethernet and camera
are not claimed fixed. No fan, power, EFI or Windows boot settings are changed.
